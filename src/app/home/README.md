# 📊 Dashboard

La **Página de Inicio** es tu centro de operaciones diario. Si no tenés ninguna aplicación activa, verás una pantalla de bienvenida invitándote a crear una. Una vez que tengas infraestructura desplegada, se activará tu **Dashboard**.

### ⚡ Operaciones Rápidas
Cada aplicación en tu dashboard cuenta con accesos directos para gestionarla en un solo clic:
* **Crear Instancia:** Desiega una copia nueva de tu entorno.
* **Editar:** Abre la estructura en el laboratorio para hacer ajustes.
* **Borrar:** Elimina la aplicación y libera los recursos del sistema.

### 📈 Diagnóstico y Detalle de la Aplicación
Si hacés clic en los detalles de una aplicación específica, vas a acceder a tres herramientas fundamentales de diagnóstico:

1.  **📊 Estadísticas en Vivo (Métricas):** Gráficos en tiempo real del consumo de hardware de tus contenedores:
    * **CPU:** Uso de procesamiento.
    * **Memoria:** Consumo de RAM actual.
    * **Red:** Tráfico de datos entrante y saliente.
    * **E/S (Entrada/Salida):** Velocidad de lectura y escritura en el disco.
2.  **📋 Logs:** El historial de eventos y registros del sistema. Es el primer lugar donde mirar si algo no está funcionando como debería.
3.  **⚠️ Alertas Personalizadas:** Configuraciones visuales que te avisan de manera inmediata si algún parámetro o métrica de salud excede los límites normales.

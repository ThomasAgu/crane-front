# 🛠️ Guía de Uso: El Laboratorio

El **Laboratorio** es tu lienzo interactivo (FlowChart) para modelar y desplegar la arquitectura de tus aplicaciones. Olvidate de las consolas: acá manejás todo de forma visual.

### 📋 ¿Cómo empezar un diseño?
Al ingresar al Laboratorio, se abrirá un **Selector de Plantillas (Templates)**. Podés:
1.  **Partir desde una estructura existente:** Seleccionar un template preconfigurado para ahorrar tiempo.
2.  **Lienzo en blanco:** Diseñar tu infraestructura completamente desde cero.

### 🧩 Elementos del Pizarrón
Dentro del lienzo, vas a poder interactuar y conectar cuatro componentes fundamentales para armar tu arquitectura:

* **📦 APP / SERVICIOS:** Representa los contenedores o procesos principales de tu aplicación.
* **🌐 REDES:** Te permite conectar tus servicios entre sí de forma segura y aislar el tráfico.
* **💾 VOLÚMENES:** Espacios de almacenamiento persistente para que tus datos no se pierdan cuando los servicios se reinicien.

---
👉 **Consejo pro:** Podés modificar tanto tus propias aplicaciones creadas previamente como aquellas que hayas descargado desde el repositorio comunitario.
